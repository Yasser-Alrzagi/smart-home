# سياسة الإشعارات — D6

## الملخص

الإشعارات سجلٌّ موثّق يجمع في مكان واحد ما يمس المستخدم: نتائج القرارات،
تحديثات الشكاوى والصيانة، تأكيد التسجيلات، والبلاغات الطارئة. تُنشأ **داخل
معاملة الحدث نفسها** — أي عملية ناجحة قد تترك إشعاراً، وأي عملية فاشلة لا
تترك وراءها شيئاً (لا إشعارات يتيمة).

## من يُخطر مَن؟

| الحدث | المستلم |
|---|---|
| تسجيل طالب في فترة مفتوحة | الطالب (تأكيد) + الضباط المالكون للنوع (تنبيه) |
| إلغاء تسجيل | الطالب (تأكيد) |
| شكوى جديدة | إدارة السكن (كل الأعضاء النشطين بالدور) |
| تحديث شكوى (حل/إغلاق) | الطالب صاحب الشكوى |
| طلب صيانة جديد | مسؤولو الصيانة |
| تحديث طلب صيانة (إسناد/تنفيذ/حل/إغلاق) | الطالب صاحب الطلب |
| طلب إذن غياب جديد | شؤون الطلاب |
| قرار إذن (موافقة/رفض) | الطالب |
| بلاغ حالة طارئة | شؤون الطلاب |
| توثيق/إغلاق بلاغ طارئ | الطالب |

- الفاعل لا يُخطَر بنتيجة فعله (استثناء `exclude_user_id`).
- إن لم يوجد عضو نشط بالدور المستهدف فلا إشعار — لا فشل ولا «رسالة ميتة».

## قواعد الصندوق

- **القراءة لصاحبها فقط**: تعليم إشعار شخصٍ آخر كمقروء يُرفض (404، دون كشف
  وجوده)، وكل الاستعلامات مفلترة بـ `user_id` من التوكن.
- **لا كتابة محتوى من العميل**: لا تُنشأ إشعارات ولا تُعدَّل ولا تُحذف عبر
  API — لا تسجيل عام ولا انتحال.
- القراءة انتقال `Unread → Read` فقط (لا عودة)، ويُسجَّل في `audit_events`
  (`notification.read` / `notification.read_all`) في المعاملة نفسها.
- التفاصيل المسجلة في التدقيق: معرّفات وأرقام فقط (`notification_id`, `count`).

## واجهة API

| المسار | الفعل |
|---|---|
| `GET /notifications/my` | صندوقي (ترتيب تنازلي، ترقيم) |
| `GET /notifications/unread-count` | عدّاد غير المقروء (للجرس) |
| `POST /notifications/{id}/read` | تعليم إشعار جانبي كمقروء |
| `POST /notifications/read-all` | تعليم الكل كمقروء |

الواجهة العربية: بند «الإشعارات» بجانب «الأمان والجلسات» بكل الأدوار، مع
عدّاد غير المقروء في التسمية، وزرّي «تعليم كمقروء» و«تعليم الكل كمقروء».

## ما لا يفعله D6

- لا إشعارات فورية (WebSocket/بريد/رسائل) — التسليم عبر البوابة فقط.
- لا إعدادات تخصيص لكل مستخدم، ولا حذف/أرشفة ذاتية (الاحتفاظ يُحدَّد لاحقاً
  مع سياسة بقاء سجل التدقيق).
- لا إشعارات لقرارات السكن (D4) أو الطلبات (D3) في هذه الدفعة.
