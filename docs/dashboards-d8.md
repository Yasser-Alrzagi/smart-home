# D8 — لوحات الضباط

دفعة الثامن: **لوحة ملخص واحدة لكل دور** (`GET /api/v1/dashboards/me`) تعرض ما يخص الدور بالضبط — أرقاماً وإشارات انتباه وأحدث العناصر وإجراءات سريعة — دون أي كتابة أو أحداث تدقيق.

## 1. القاعدة

- **قراءة فقط**: لا تعديل، لا إنشاء، ولا `audit` (لا شيء يُسجل).
- **مصفوفة الأدوار الثابتة نفسها** المستخدمة في كل العمليات: كل دور يرى أرقام نطاقه فقط، ولا يوجد أي معامل دور في الطلب — الهوية من الجلسة حصراً.
- الشكل موحد لكل الأدوار: `stats` (أرقام عامة) + `attention` (ما يحتاج إجراءاً) + `latest` (أحدث 5–6 عناصر) + `actions` (روابط صفحات البوابة).

## 2. ماذا يرى كل دور

| الدور | الأرقام | الانتباه | الأحدث |
|---|---|---|---|
| الطالب | طلبات السكن، الغياب الموثق، الإشعارات غير المقروءة، سكن نشط | إشعارات غير مقروءة، إذن معلق | طلباته وغيابه |
| شؤون الطلاب | طلبات قيد المراجعة، أذون معلقة، بلاغات طارئة معلقة | كل ما قيمته > 0 | الطلبات/الأذون/البلاغات |
| إدارة السكن | الغرف، المشغول، بانتظار غرفة، شكاوى مفتوحة، غائبون اليوم | بانتظار قرارك، بانتظار تسكين، شكاوى، غائبون الغياب دون تغطية | حضور اليوم، الشكاوى، طلبات جاهزة للقرار |
| مسؤول الصيانة | بانتظار الإسناد، مُسندة، جاري التنفيذ، إجمالي المفتوحة | غير المغلقة | طلبات الصيانة |
| مسؤولو الخدمات (أنشطة/تغذية/رياضة) | خدماتهم، فترات مفتوحة، قادمة، إجمالي التسجيلات | فترات مفتوحة تستقبل تسجيلاً؛ تنبيه إن لا خدمات | فتراتهم وآخر التسجيلات |
| مسؤول النظافة | دورات النظافة، بانتظار الموافقة، نشطة، مهام معلقة | ما يحتاج متابعة | الدورات |
| مسؤول النظام | إجمالي الحسابات، النشطة، بانتظار تغيير الكلمة، الجلسات النشطة | حسابات لم تغيّر كلمتها | أحدث الحسابات |

ملاحظات:
- «غائبون اليوم» = سجل الحضور اليومي (D7) لحالة `absent` في تاريخ اليوم.
- «بانتظار غرفة» = نفس تعريف D4 (طلب مقبول دون تسكين نشط).
- «جلسات نشطة» من `auth_sessions` بلا إبطال.

## 3. نقاط النهاية

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/api/v1/dashboards/me` | ملخص دور المستخدم الحالي (كل الأدوار، بلا استثناء) |

## 4. الواجهة

- الصفحة الرئيسية للبوابة تعرض الآن **لوحة القيادة الموحدة** لكل الأدوار غير الطالب، بينما تبقى رحلة الطلب للطالب كما هي.
- اللوحة: بطاقات الأرقام ← «يحتاج انتباهك» ← «الأحدث» ← أزرار «إجراءات سريعة» تنقل للصفحة المناسبة (السكن/الحضور/الشكاوى/الخدمات/الحسابات…).

## 5. التحقق

- `tests/integration/test_products_dashboards.py` — 5 سيناريوهات HTTP/DB: عقد لكل الأدوار التسعة (شكل الاستجابة)، أذون شؤون الطلاب، شكاوى/غرف إدارة السكن، صيانة+خدمة (عبر دورة الفترة الحقيقية إلى `Open`)، ومسؤول النظام/الطالب.
