# مشروع الذكاء الاصطناعي — تحسين جدولة مهام النظافة (BFS و A*)

الموضوع: **نظام ذكاء اصطناعي لجدولة وتوزيع مهام نظافة الطوابق في سكن جامعي**
(المرجع في قائمة الأفكار الرسمية: «Smart Home Automation» / خدمات المنزل الذكي)

---

## 1) وثيقة الاقتراح — التسليم الأول (أسبوع 7)

> صفحة إلى صفحتين حسب تعليمات المادة — املأ أسماء أعضاء الفريق قبل الرفع.

**وصف المشروع:** السكن الجامعي يضم طوابق، كل طابق غرفاً بمستويات اتساخ مختلفة (بيانات
قاعدة بيانات النظام). يريد مسؤول النظافة توزيع الموظفين على المهام بحيث تُغطى كل غرفة
ضمن يوم واحد بأقل وقت/أقل تكلفة حركة. نبني **خوارزميتين** تحددان التوزيع الأمثل
وتقارنان أداءهما.

**خوارزميات الذكاء الاصطناعي (من تنفيذ الفريق، بلا أي API خارجي):**
- **BFS** — بحث أعمى يضمن إيجاد الحل إن وُجد (الأمثلية عند تكلفة موحدة).
- **A*** — بحث إرشادي بـ heuristic (عدد الغرف المتبقية × أصغر تكلفة تقديرية) يقلل
  حالات الاستكشاف مع الاحتفاظ بأمثلية الحل عند ضمان الاتساق.

كلا الخوارزميتين **جوهر حل المشكلة** (توليد جدول المهام)، وتُدار بنمط **Strategy**
وتقارن بمعطيات: عدد الحالات المفتوحة، النقاط الموسعة، زمن التنفيذ، تكلفة الحل.

**المعطيات:** طوابق/غرف/طلاب/دورات نظافة من قاعدة MySQL للنظام (لا يوجد نموذج تعلّم
آلي — خوارزميات بحث؛ فلا حاجة لمجموعة تدريب، والتقييم بـمقارنة خوارزميتين على نفس
البيانات).

**نوع الواجهة:** واجهة ويب عربية + عميل سطح مكتب (Tkinter) — كلاهما يقدّم «دورة النظافة»
ويستدعي `/api/v1/cleaning/*`.

**التقنيات:** Python 3.13، FastAPI، SQLAlchemy، MySQL/MariaDB، Tkinter، JWT، pytest.

**خطة تنفيذ موجزة:** البنية والبيانات (جداول طوابق/غرف/مهام) → تنفيذ BFS و A* في
`cleaning_ai.py` → تكامل REST (`/cycles`, `/optimize`) → مقارنة وقياس → واجهة الويب
والسطح المكتب → التوثيق والعرض.

**أعضاء الفريق (مجموعة من طالبين):**
- ياسر عبدالسلام الرزاقي
- شهاب الدين فهد رعدان

> ملاحظة: وفق شرط المجموعات (متطلب 9) تُطبَّق خوارزميتان مختلفتان — **BFS و A*** — حاضِرتان في الكود.

### توزيع مهام الذكاء الاصطناعي فقط (بين العضوين — توزيع عادل)

**نطاق هذا التوزيع:** مهام مادة الذكاء الاصطناعي حصراً (المشكلة، البيانات، الخوارزميتان،
التقييم، اختبارات الذكاء، واجهة تطبيق الذكاء، توثيق الذكاء، العرض الحي).
**خارج النطاق:** أدوار نظام «سكن بازرعة» ككل (المحاكمات، السكن، الحسابات، الخدمات…)
تُوزَّع في وثيقة البرمجة المتقدمة ولا تدخل هنا.

**مبدأ العدالة:** كل عضو يملك **خوارزمية كاملة من البداية للنهاية** + **طبقة واحدة
بالتساوي** (ياسر: التقييم/التصميم — شهاب: البيانات/الواجهة) + جزء متساوٍ من
التوثيق والعرض. 6 مهام لكل عضو بالضبط.

| # | المهمة (ذكاء اصطناعي فقط) | المسؤول |
|---|---|---|
| 1 | صياغة المشكلة، وتبرير اختيار الخوارزميتين (لماذا BFS − لماذا A*) | **ياسر** |
| 2 | تنفيذ خوارزمية **A***: الإرشاد المقبول `h`، طابور الأولوية، أمثولية الحل، حد العقد | **ياسر** |
| 3 | التقييم والمقارنة: `nodes / elapsed / total_cost / fairness` + جداول BFS ضد A* | **ياسر** |
| 4 | اختبارات A* واختبارات الأمثولية (قيم صغيرة مقابل بحث شامل) | **ياسر** |
| 5 | تصميم OOP/SRP لوحدة الذكاء (نمط Strategy بين الخوارزميتين، فصل عن قاعدة البيانات) | **ياسر** |
| 6 | توثيق أقسام (المشكلة، الخوارزميات، التقييم) في الاقتراح والتقرير | **ياسر** |
| 7 | جمع البيانات والمعالجة المسبقة: تجميع يومي `_group_by_day`، الجدوى `_feasibility_check`، السقف `cap`، حالات القياس | **شهاب** |
| 8 | تنفيذ خوارزمية **BFS**: توسيع طبقي يوم بيوم، اختيار الأقل حمولة، الحتمية | **شهاب** |
| 9 | قاعدة بيانات تطبيق الذكاء (جداول دورات/مهام/تشغيل النظافة) — متطلب «DB Integration» رقم 10 | **شهاب** |
| 10 | واجهة تطبيق الذكاء (صفحة «النظافة AI» في البوابة + تبويب المهام في المكتبي) — متطلب «User Interface» رقم 5 | **شهاب** |
| 11 | اختبارات BFS وتكامل وحدة الذكاء (دورة الحياة عبر REST) | **شهاب** |
| 12 | توثيق أقسام (البيانات، الواجهة، دليل الاستخدام) في الاقتراح والتقرير | **شهاب** |
| 13 | التقرير النهائي الكامل والمراجعة النهائية | **الاثنان معاً** |
| 14 | العرض الحي أمام اللجنة: ياسر يشرح A* والنتائج — شهاب يشرح BFS والواجهات | **الاثنان معاً** |

**تناوب إدارة المشروع (كما تشترط المادة):**
- الأسابيع 1–4: ياسر منسقاً — الخطة، متابعة المهمتين 2 و8، حفظ السجلات.
- الأسابيع 5–8: شهاب منسقاً — متابعة المهمتين 9 و10 ومواعيد التسليم.
- الأسابيع 9–11: الاثنان بالتناوب — المراجعة والرفع والعرض.

**أدوات التواصل وإدارة الإصدارات:** WhatsApp للمتابعة + GitHub (فروع/مراجعات) — مطابقة
لما اتبع في مراحل D1–D9 الموثقة.

**المراجع:** Russell & Norvig, *Artificial Intelligence: A Modern Approach* (الفصل الخاص
بالبحث الإرشادي)؛ التوثيق الداخلي `docs/cleaning-d9.md`.
