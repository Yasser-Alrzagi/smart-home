# مشروع الذكاء الاصطناعي — تحسين جدولة مهام النظافة (BFS و A*)

الموضوع: **نظام ذكاء اصطناعي لجدولة وتوزيع مهام نظافة الطوابق في سكن جامعي**
(المرجع في قائمة الأفكار الرسمية: «Smart Home Automation» / خدمات المنزل الذكي)

---

## 1) وثيقة الاقتراح — التسليم الأول (أسبوع 7)

> صفحة إلى صفحتين حسب تعليمات المادة — املأ أسماء أعضاء الفريق قبل الرفع.

**وصف المشروع:** السكن الجامعي يضم طوابق، كل طابق غرفاً بمستويات اتساخ مختلفة (بيانات
قاعدة بيانات النظام). يريد مسؤول النظافة توزيع الموظفين على المهام بحيث تُغطى كل غرفة
ضمن يوم واحد بأقل وقت/أقل تكلفة حركة. نبني **خوارزميتين** تحددان التوزيع الأمثل
وتقارنان أداءهما.

**خوارزميات الذكاء الاصطناعي (من تنفيذ الفريق، بلا أي API خارجي):**
- **BFS** — بحث أعمى يضمن إيجاد الحل إن وُجد (الأمثلية عند تكلفة موحدة).
- **A*** — بحث إرشادي بـ heuristic (عدد الغرف المتبقية × أصغر تكلفة تقديرية) يقلل
  حالات الاستكشاف مع الاحتفاظ بأمثلية الحل عند ضمان الاتساق.

كلا الخوارزميتين **جوهر حل المشكلة** (توليد جدول المهام)، وتُدار بنمط **Strategy**
وتقارن بمعطيات: عدد الحالات المفتوحة، النقاط الموسعة، زمن التنفيذ، تكلفة الحل.

**المعطيات:** طوابق/غرف/طلاب/دورات نظافة من قاعدة MySQL للنظام (لا يوجد نموذج تعلّم
آلي — خوارزميات بحث؛ فلا حاجة لمجموعة تدريب، والتقييم بـمقارنة خوارزميتين على نفس
البيانات).

**نوع الواجهة:** واجهة ويب عربية + عميل سطح مكتب (Tkinter) — كلاهما يقدّم «دورة النظافة»
ويستدعي `/api/v1/cleaning/*`.

**التقنيات:** Python 3.13، FastAPI، SQLAlchemy، MySQL/MariaDB، Tkinter، JWT، pytest.

**خطة تنفيذ موجزة:** البنية والبيانات (جداول طوابق/غرف/مهام) → تنفيذ BFS و A* في
`cleaning_ai.py` → تكامل REST (`/cycles`, `/optimize`) → مقارنة وقياس → واجهة الويب
والسطح المكتب → التوثيق والعرض.

**أعضاء الفريق وأدوارهم:** (يُكتب الاسم والدور — يُفضَّل عمل فردي، والمجموعة كحد أقصى 3)

**المراجع:** Russell & Norvig, *Artificial Intelligence: A Modern Approach* (الفصل الخاص
بالبحث الإرشادي)؛ التوثيق الداخلي `docs/cleaning-d9.md`.

1. نظرة عامة + المشكلة (§1).

5. التحديات والحلول (مثال حقيقي: تغيير مقارنة `role` من قيمة نصية إلى Enum — 403).
6. دليل المستخدم.
7. ملخص + أعضاء الفريق والأدوار.
