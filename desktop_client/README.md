# عميل سطح المكتب — سكن بازرعة (المنصة الثانية)

هذا التطبيق هو **المنصة الثانية** المطلوبة في مادة البرمجة المتقدمة (Web + Desktop).
هو عميل سطح مكتب بواجهة عربية مبنية بـ **Tkinter** (مضمنة في بايثون — لا يحتاج أي
تثبيت إضافي)، ويستهلك **نفس REST API** الذي يستخدمه الموقع، ويتصل **بنفس قاعدة
البيانات** حصراً عبر HTTP.

## التشغيل على Windows

1. شغّل الخادم (نافذة أولى):
   ```bat
   cd /d C:\Users\pc\smart-home
   .venv\Scripts\activate.bat
   python main.py
   ```
2. افتح نافذة أوامر ثانية وشغّل العميل (لا يحتاج تفعيل البيئة — مكتبات قياسية فقط):
   ```bat
   cd /d C:\Users\pc\smart-home
   python desktop_client\main.py
   ```
   لتحديد عنوان خادم مختلف:
   ```bat
   python desktop_client\main.py --api http://127.0.0.1:8000
   ```

## المزايا

| الواجهة | الوصف |
|---|---|
| تسجيل الدخول | عبر `POST /auth/login/access-token` (JWT، يبقى في الذاكرة فقط) |
| إجبار تغيير كلمة المرور | نفس سياسة D2: إن كان `must_change_password` صحيحاً تُفتح شاشة التغيير أولاً |
| نظرة عامة | ملخص الدور من `/dashboards/me` |
| الحسابات | مسؤول النظام فقط: عرض + إنشاء حسابات (`GET/POST /users`) |
| طلبات السكن | طالب / شؤون الطلاب / إدارة السكن فقط (`GET /applications`) |
| الإشعارات | صندوق البريد الشخصي + عدّاد غير المقروء |
| كلمة المرور | تغيير ذاتي (`POST /auth/change-password`) |
| تسجيل الخروج | يُبطل الجلسة في الخادم ويمسح التوكن محلياً |

## لماذا Tkinter؟
- **مكتبة مدمجة** في بايثون (الشرط: منصتان تشتركان في قاعدة بيانات واحدة عبر REST).
- لا إضافات pip، لا محاكي، لا ملفات إعداد — يعمل بأمر واحد.
- يمكن عكس الموقع والواجهة لتوضيح أن كليهما مجرد «عميل» لنفس الواجهات.

## البنية
```
desktop_client/

```
